## Questions

!!! question "Assign oxidation number to: <br>(a) P in NaH<sub>2</sub>PO<sub>4</sub> (b) S in NaHSO<sub>4</sub> (c) P in H<sub>4</sub>P<sub>2</sub>O<sub>7</sub> (d) Mn in K<sub>2</sub>MnO<sub>4</sub> <br>(e) O in CaO<sub>2</sub> (f) B in NaBH<sub>4</sub> (g) S in H<sub>2</sub>S<sub>2</sub>O<sub>7</sub> (h) S in KAl(SO<sub>4</sub>)<sub>2</sub>.12H<sub>2</sub>O"

    Let the oxidation number of the required element be x.

    $$(a)\ NaH_2PO_4:\ +1 + 2(+1) + x + 4(-2) = 0 &rArr; x = +5$$

    $$(b)\ NaHSO_4:\ +1 + 1 + x + 4(-2) = 0 &rArr; x = +6$$

    $$(c)\ H_4P_2O_7:\ 4(+1) + 2x + 7(-2) = 0 &rArr; x = +5$$

    $$(d)\ K_2MnO_4:\ 2(+1) + x + 4(-2) = 0 &rArr; x = +6$$

    * (e) CaO<sub>2</sub> is a peroxide:

    $$+2 + 2x = 0 &rArr; x = -1$$

    * (f) NaBH<sub>4</sub> is a metal hydride, so H is -1:

    $$+1 + x + 4(-1) = 0 &rArr; x = +3$$

    $$(g)\ H_2S_2O_7:\ 2(+1) + 2x + 7(-2) = 0 &rArr; x = +6$$

    * (h) Water molecules are neutral, so they contribute zero:

    $$+1 + 3 + 2x + 8(-2) = 0 &rArr; x = +6$$

!!! question "What are the oxidation numbers of the following and how do you rationalise your results? <br>(a) I in KI<sub>3</sub> (b) S in H<sub>2</sub>S<sub>4</sub>O<sub>6</sub> (c) Fe in Fe<sub>3</sub>O<sub>4</sub> (d) C in CH<sub>3</sub>CH<sub>2</sub>OH (e) C in CH<sub>3</sub>COOH"

    * (a) By formula, the average oxidation number of I is $-{1 \over 3}$. But KI<sub>3</sub> is K<sup>+</sup>[I<sub>2</sub>.I<sup>-</sup>]: two iodine atoms (the I<sub>2</sub> molecule) are 0 and one (the I<sup>-</sup> ion) is -1.

    * (b) The average oxidation number of S is +2.5. In the structure of S<sub>4</sub>O<sub>6</sub><sup>2-</sup>, the two terminal S atoms are +5 and the two middle S atoms are 0.

    * (c) The average oxidation number of Fe is $+{8 \over 3}$. Fe<sub>3</sub>O<sub>4</sub> is a mixed oxide, FeO.Fe<sub>2</sub>O<sub>3</sub>: one Fe is +2 and two Fe are +3.

    * (d) The average oxidation number of C is -2. Counting each C separately (C-C bond contributes 0, each H contributes -1, each O contributes +1):

    $$\overset{-3}{C}H_3 - \overset{-1}{C}H_2OH$$

    * (e) The average oxidation number of C is 0. Counting separately:

    $$\overset{-3}{C}H_3 - \overset{+3}{C}OOH$$

!!! question "Justify that the following reactions are redox reactions: <br>(a) CuO<sub>(s)</sub> + H<sub>2(g)</sub> &rarr; Cu<sub>(s)</sub> + H<sub>2</sub>O<sub>(g)</sub> <br>(b) Fe<sub>2</sub>O<sub>3(s)</sub> + 3CO<sub>(g)</sub> &rarr; 2Fe<sub>(s)</sub> + 3CO<sub>2(g)</sub> <br>(c) 2K<sub>(s)</sub> + F<sub>2(g)</sub> &rarr; 2K<sup>+</sup>F<sup>-</sup><sub>(s)</sub> <br>(d) 4NH<sub>3(g)</sub> + 5O<sub>2(g)</sub> &rarr; 4NO<sub>(g)</sub> + 6H<sub>2</sub>O<sub>(g)</sub>"

    $$(a)\ \overset{+2}{Cu}O + \overset{0}{H_2} &rarr; \overset{0}{Cu} + \overset{+1}{H_2}O$$

    Cu is reduced (+2 to 0) and H is oxidised (0 to +1).

    $$(b)\ \overset{+3}{Fe_2}O_3 + 3\overset{+2}{C}O &rarr; 2\overset{0}{Fe} + 3\overset{+4}{C}O_2$$

    Fe is reduced (+3 to 0) and C is oxidised (+2 to +4).

    $$(c)\ 2\overset{0}{K} + \overset{0}{F_2} &rarr; 2\overset{+1}{K}\overset{-1}{F}$$

    K is oxidised (0 to +1) and F is reduced (0 to -1).

    $$(d)\ 4\overset{-3}{N}H_3 + 5\overset{0}{O_2} &rarr; 4\overset{+2}{N}\overset{-2}{O} + 6H_2\overset{-2}{O}$$

    N is oxidised (-3 to +2) and O is reduced (0 to -2).

    In each reaction, one element is oxidised and another is reduced, so all are redox reactions.

!!! question "Fluorine reacts with ice: H<sub>2</sub>O<sub>(s)</sub> + F<sub>2(g)</sub> &rarr; HF<sub>(g)</sub> + HOF<sub>(g)</sub>. Justify that this is a redox reaction."

    In HOF, fluorine is the most electronegative atom (-1) and H is +1, so oxygen is 0.

    $$H_2\overset{-2}{O} + \overset{0}{F_2} &rarr; H\overset{-1}{F} + H\overset{0}{O}\overset{-1}{F}$$

    Oxygen is oxidised from -2 to 0 and fluorine is reduced from 0 to -1. Hence, it is a redox reaction.

!!! question "Calculate the oxidation number of sulphur, chromium and nitrogen in H<sub>2</sub>SO<sub>5</sub>, Cr<sub>2</sub>O<sub>7</sub><sup>2-</sup> and NO<sub>3</sub><sup>-</sup>. Suggest structures of these compounds. Count for the fallacy."

    * **H<sub>2</sub>SO<sub>5</sub>:** Taking all O as -2:

    $$2(+1) + x + 5(-2) = 0 &rArr; x = +8$$

    This is impossible because sulphur cannot exceed +6 (it has only six valence electrons). The fallacy is that H<sub>2</sub>SO<sub>5</sub> (peroxomonosulphuric acid, HO-SO<sub>2</sub>-O-O-H) contains one peroxide (O-O) linkage, where each of the two oxygens is -1:

    $$2(+1) + x + 3(-2) + 2(-1) = 0 &rArr; x = +6$$

    * **Cr<sub>2</sub>O<sub>7</sub><sup>2-</sup>:**

    $$2x + 7(-2) = -2 &rArr; x = +6$$

    The structure has two CrO<sub>3</sub> units joined by a bridging oxygen; there is no peroxide linkage, so +6 is correct and there is no fallacy.

    * **NO<sub>3</sub><sup>-</sup>:**

    $$x + 3(-2) = -1 &rArr; x = +5$$

    In the structure, N forms one N=O double bond, one N-O<sup>-</sup> single bond and one coordinate bond N&rarr;O. N cannot form five covalent bonds (no d-orbitals), but its oxidation number is still +5 since all its five valence electrons are counted towards oxygen.

!!! question "While sulphur dioxide and hydrogen peroxide can act as oxidising as well as reducing agents, ozone and nitric acid act only as oxidants. Why?"

    * In SO<sub>2</sub>, S is +4. Sulphur can range from -2 to +6, so its oxidation number can either increase or decrease. Hence SO<sub>2</sub> can act as both a reductant and an oxidant.

    * In H<sub>2</sub>O<sub>2</sub>, O is -1. It can increase to 0 (in O<sub>2</sub>) or decrease to -2 (in H<sub>2</sub>O), so H<sub>2</sub>O<sub>2</sub> can also act both ways.

    * In HNO<sub>3</sub>, N is +5, its highest oxidation state. It can only decrease, so HNO<sub>3</sub> acts only as an oxidant.

    * In O<sub>3</sub>, O is 0. Oxygen can decrease to -2 but cannot show positive oxidation states (except with fluorine). Ozone readily gives O<sub>2</sub> and an oxygen atom, which is a strong oxidant. So ozone acts only as an oxidant.

!!! question "The compound AgF<sub>2</sub> is unstable. However, if formed, it acts as a very strong oxidising agent. Why?"

    In AgF<sub>2</sub>, silver is in the +2 state, which is unstable. Silver strongly tends to accept an electron and return to its stable +1 state. This makes AgF<sub>2</sub> a very strong oxidising agent.

!!! question "What information can you draw from the reaction: (CN)<sub>2(g)</sub> + 2OH<sup>-</sup><sub>(aq)</sub> &rarr; CN<sup>-</sup><sub>(aq)</sub> + CNO<sup>-</sup><sub>(aq)</sub> + H<sub>2</sub>O<sub>(l)</sub>?"

    Taking N as -3, the oxidation number of carbon is:

    $$(\overset{+3}{C}N)_2 + 2OH^- &rarr; \overset{+2}{C}N^- + \overset{+4}{C}NO^- + H_2O$$

    * Carbon in cyanogen (+3) is simultaneously reduced to +2 (cyanide) and oxidised to +4 (cyanate). So this is a **disproportionation** reaction of cyanogen in alkaline medium.

!!! question "Consider the elements Cs, Ne, I and F. Identify the element that exhibits: (a) only negative oxidation state (b) only positive oxidation state (c) both positive and negative oxidation states (d) neither negative nor positive oxidation state."

    * (a) **F** - being the most electronegative element, it shows only -1.

    * (b) **Cs** - an alkali metal, it shows only +1.

    * (c) **I** - shows -1 in iodides and +1, +3, +5, +7 in its oxo compounds.

    * (d) **Ne** - a noble gas, it shows neither.
