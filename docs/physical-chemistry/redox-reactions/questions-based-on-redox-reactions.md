## Balancing Redox Equations

!!! question "Balance by the ion-electron method: MnO<sub>4</sub><sup>-</sup><sub>(aq)</sub> + I<sup>-</sup><sub>(aq)</sub> &rarr; MnO<sub>2(s)</sub> + I<sub>2(s)</sub> (in basic medium)"

    $$Oxidation:\ 2I^- &rarr; I_2 + 2e^-$$

    $$Reduction:\ MnO_4^- + 2H_2O + 3e^- &rarr; MnO_2 + 4OH^-$$

    * Multiply the oxidation half by 3 and the reduction half by 2, then add:

    $$2MnO_4^-{}_{(aq)} + 6I^-_{(aq)} + 4H_2O_{(l)} &rarr; 2MnO_{2(s)} + 3I_{2(s)} + 8OH^-_{(aq)}$$

!!! question "Balance by the ion-electron method: MnO<sub>4</sub><sup>-</sup><sub>(aq)</sub> + SO<sub>2(g)</sub> &rarr; Mn<sup>2+</sup><sub>(aq)</sub> + HSO<sub>4</sub><sup>-</sup><sub>(aq)</sub> (in acidic solution)"

    $$Oxidation:\ SO_2 + 2H_2O &rarr; HSO_4^- + 3H^+ + 2e^-$$

    $$Reduction:\ MnO_4^- + 8H^+ + 5e^- &rarr; Mn^{2+} + 4H_2O$$

    * Multiply the oxidation half by 5 and the reduction half by 2:

    $$5SO_2 + 10H_2O &rarr; 5HSO_4^- + 15H^+ + 10e^-$$

    $$2MnO_4^- + 16H^+ + 10e^- &rarr; 2Mn^{2+} + 8H_2O$$

    * Add and cancel the common H<sup>+</sup> and H<sub>2</sub>O:

    $$2MnO_4^-{}_{(aq)} + 5SO_{2(g)} + 2H_2O_{(l)} + H^+_{(aq)} &rarr; 2Mn^{2+}_{(aq)} + 5HSO_4^-{}_{(aq)}$$

!!! question "Balance by the ion-electron method: H<sub>2</sub>O<sub>2(aq)</sub> + Fe<sup>2+</sup><sub>(aq)</sub> &rarr; Fe<sup>3+</sup><sub>(aq)</sub> + H<sub>2</sub>O<sub>(l)</sub> (in acidic solution)"

    $$Oxidation:\ 2Fe^{2+} &rarr; 2Fe^{3+} + 2e^-$$

    $$Reduction:\ H_2O_2 + 2H^+ + 2e^- &rarr; 2H_2O$$

    $$Overall:\ H_2O_{2(aq)} + 2Fe^{2+}_{(aq)} + 2H^+_{(aq)} &rarr; 2Fe^{3+}_{(aq)} + 2H_2O_{(l)}$$

!!! question "Balance by the ion-electron method: Cr<sub>2</sub>O<sub>7</sub><sup>2-</sup> + SO<sub>2(g)</sub> &rarr; Cr<sup>3+</sup><sub>(aq)</sub> + SO<sub>4</sub><sup>2-</sup><sub>(aq)</sub> (in acidic solution)"

    $$Oxidation:\ 3SO_2 + 6H_2O &rarr; 3SO_4^{2-} + 12H^+ + 6e^-$$

    $$Reduction:\ Cr_2O_7^{2-} + 14H^+ + 6e^- &rarr; 2Cr^{3+} + 7H_2O$$

    * Add and cancel 12H<sup>+</sup> and 6H<sub>2</sub>O from both sides:

    $$Cr_2O_7^{2-}{}_{(aq)} + 3SO_{2(g)} + 2H^+_{(aq)} &rarr; 2Cr^{3+}_{(aq)} + 3SO_4^{2-}{}_{(aq)} + H_2O_{(l)}$$

!!! question "Balance in basic medium and identify the oxidising and reducing agents: N<sub>2</sub>H<sub>4(l)</sub> + ClO<sub>3</sub><sup>-</sup><sub>(aq)</sub> &rarr; NO<sub>(g)</sub> + Cl<sup>-</sup><sub>(aq)</sub>"

    * Using the oxidation number method:

    $$\overset{-2}{N_2}H_4 + \overset{+5}{Cl}O_3^- &rarr; \overset{+2}{N}O + \overset{-1}{Cl^-}$$

    * Each N increases by 4, so N<sub>2</sub>H<sub>4</sub> increases by 8. Cl decreases by 6. LCM of 8 and 6 is 24, so take 3N<sub>2</sub>H<sub>4</sub> and 4ClO<sub>3</sub><sup>-</sup>:

    $$3N_2H_4 + 4ClO_3^- &rarr; 6NO + 4Cl^-$$

    * Charges are already equal (-4 on each side). Balance H by adding 6H<sub>2</sub>O on the right:

    $$3N_2H_{4(l)} + 4ClO_3^-{}_{(aq)} &rarr; 6NO_{(g)} + 4Cl^-_{(aq)} + 6H_2O_{(l)}$$

    * Oxidising agent: ClO<sub>3</sub><sup>-</sup>. Reducing agent: N<sub>2</sub>H<sub>4</sub>.

!!! question "Balance in basic medium and identify the oxidising and reducing agents: Cl<sub>2</sub>O<sub>7(g)</sub> + H<sub>2</sub>O<sub>2(aq)</sub> &rarr; ClO<sub>2</sub><sup>-</sup><sub>(aq)</sub> + O<sub>2(g)</sub>"

    $$\overset{+7}{Cl_2}O_7 + H_2\overset{-1}{O_2} &rarr; \overset{+3}{Cl}O_2^- + \overset{0}{O_2}$$

    * Each Cl decreases by 4, so Cl<sub>2</sub>O<sub>7</sub> decreases by 8. Each H<sub>2</sub>O<sub>2</sub> increases by 2. So take 4H<sub>2</sub>O<sub>2</sub>:

    $$Cl_2O_7 + 4H_2O_2 &rarr; 2ClO_2^- + 4O_2$$

    * Charge on left = 0, on right = -2. Add 2OH<sup>-</sup> on the left. Then balance H with 5H<sub>2</sub>O on the right:

    $$Cl_2O_{7(g)} + 4H_2O_{2(aq)} + 2OH^-_{(aq)} &rarr; 2ClO_2^-{}_{(aq)} + 4O_{2(g)} + 5H_2O_{(l)}$$

    * Oxidising agent: Cl<sub>2</sub>O<sub>7</sub>. Reducing agent: H<sub>2</sub>O<sub>2</sub>.

!!! question "The Mn<sup>3+</sup> ion is unstable in solution and undergoes disproportionation to give Mn<sup>2+</sup>, MnO<sub>2</sub> and H<sup>+</sup> ion. Write a balanced ionic equation for the reaction."

    $$Oxidation:\ Mn^{3+} + 2H_2O &rarr; MnO_2 + 4H^+ + e^-$$

    $$Reduction:\ Mn^{3+} + e^- &rarr; Mn^{2+}$$

    $$Overall:\ 2Mn^{3+}_{(aq)} + 2H_2O_{(l)} &rarr; Mn^{2+}_{(aq)} + MnO_{2(s)} + 4H^+_{(aq)}$$

!!! question "Chlorine is used to purify drinking water. Excess chlorine is removed by treating with sulphur dioxide. Present a balanced equation for this redox change in water."

    $$Reduction:\ Cl_2 + 2e^- &rarr; 2Cl^-$$

    $$Oxidation:\ SO_2 + 2H_2O &rarr; SO_4^{2-} + 4H^+ + 2e^-$$

    $$Overall:\ Cl_{2(aq)} + SO_{2(aq)} + 2H_2O_{(l)} &rarr; 2Cl^-_{(aq)} + SO_4^{2-}{}_{(aq)} + 4H^+_{(aq)}$$

## Oxidants, Reductants and Feasibility

!!! question "Whenever a reaction between an oxidising agent and a reducing agent is carried out, a compound of lower oxidation state is formed if the reducing agent is in excess, and a compound of higher oxidation state is formed if the oxidising agent is in excess. Justify with three illustrations."

    $$(i)\ C + O_2\ (limited) &rarr; CO\ (C:\ +2),\ \ C + O_2\ (excess) &rarr; CO_2\ (C:\ +4)$$

    $$(ii)\ P_4 + 6Cl_2\ (limited) &rarr; 4PCl_3\ (P:\ +3),\ \ P_4 + 10Cl_2\ (excess) &rarr; 4PCl_5\ (P:\ +5)$$

    $$(iii)\ 4Na + O_2\ (limited) &rarr; 2Na_2O\ (O:\ -2),\ \ 2Na + O_2\ (excess) &rarr; Na_2O_2\ (O:\ -1)$$

    In (i) and (ii), the reductant (C, P<sub>4</sub>) in excess gives the lower oxidation state of the reductant. In (iii), excess oxidant O<sub>2</sub> gives Na<sub>2</sub>O<sub>2</sub>, where oxygen is in its higher oxidation state (-1 instead of -2).

!!! question "When concentrated sulphuric acid is added to an inorganic mixture containing chloride, we get colourless pungent HCl gas, but if the mixture contains bromide, we get red vapour of bromine. Why?"

    * With chloride, HCl is formed. HCl is a weak reductant and cannot reduce H<sub>2</sub>SO<sub>4</sub>:

    $$NaCl + H_2SO_4 &rarr; NaHSO_4 + HCl$$

    * With bromide, HBr is formed first. HBr is a stronger reductant and reduces H<sub>2</sub>SO<sub>4</sub> to SO<sub>2</sub>, getting oxidised to red Br<sub>2</sub>:

    $$NaBr + H_2SO_4 &rarr; NaHSO_4 + HBr$$

    $$2HBr + H_2SO_4 &rarr; Br_2 + SO_2 + 2H_2O$$

!!! question "Consider the reactions: <br>2S<sub>2</sub>O<sub>3</sub><sup>2-</sup><sub>(aq)</sub> + I<sub>2(s)</sub> &rarr; S<sub>4</sub>O<sub>6</sub><sup>2-</sup><sub>(aq)</sub> + 2I<sup>-</sup><sub>(aq)</sub> <br>S<sub>2</sub>O<sub>3</sub><sup>2-</sup><sub>(aq)</sub> + 4Br<sub>2(l)</sub> + 5H<sub>2</sub>O<sub>(l)</sub> &rarr; 2SO<sub>4</sub><sup>2-</sup><sub>(aq)</sub> + 8Br<sup>-</sup><sub>(aq)</sub> + 10H<sup>+</sup><sub>(aq)</sub> <br>Why does the same reductant, thiosulphate, react differently with iodine and bromine?"

    * In S<sub>2</sub>O<sub>3</sub><sup>2-</sup>, the average oxidation number of S is +2.

    * Iodine is a weaker oxidant, so it oxidises S only to +2.5 (in S<sub>4</sub>O<sub>6</sub><sup>2-</sup>).

    * Bromine is a stronger oxidant, so it oxidises S all the way to +6 (in SO<sub>4</sub><sup>2-</sup>).

!!! question "Justify giving reactions that among halogens, fluorine is the best oxidant and among hydrohalic compounds, hydroiodic acid is the best reductant."

    * Fluorine has the highest standard reduction potential (2.87 V) and oxidises all other halide ions:

    $$F_2 + 2X^- &rarr; 2F^- + X_2\ \ (X = Cl,\ Br,\ I)$$

    * Among HX, the H-I bond is the weakest and I<sup>-</sup> is the largest ion, so it loses its electron most easily. HI can even reduce H<sub>2</sub>SO<sub>4</sub>, which HCl cannot:

    $$2HI + H_2SO_4 &rarr; I_2 + SO_2 + 2H_2O$$

!!! question "Why does the following reaction occur? <br>XeO<sub>6</sub><sup>4-</sup><sub>(aq)</sub> + 2F<sup>-</sup><sub>(aq)</sub> + 6H<sup>+</sup><sub>(aq)</sub> &rarr; XeO<sub>3(g)</sub> + F<sub>2(g)</sub> + 3H<sub>2</sub>O<sub>(l)</sub> <br>What conclusion about Na<sub>4</sub>XeO<sub>6</sub> can be drawn from the reaction?"

    $$\overset{+8}{Xe}O_6^{4-} + 2\overset{-1}{F^-} + 6H^+ &rarr; \overset{+6}{Xe}O_3 + \overset{0}{F_2} + 3H_2O$$

    * Xe is reduced from +8 to +6 and F<sup>-</sup> is oxidised to F<sub>2</sub>. Since F<sub>2</sub> is the strongest common oxidant, XeO<sub>6</sub><sup>4-</sup> must be an even stronger oxidant. So Na<sub>4</sub>XeO<sub>6</sub> is a stronger oxidising agent than F<sub>2</sub>.

!!! question "Consider the reactions: <br>(a) H<sub>3</sub>PO<sub>2</sub> + 4AgNO<sub>3</sub> + 2H<sub>2</sub>O &rarr; H<sub>3</sub>PO<sub>4</sub> + 4Ag + 4HNO<sub>3</sub> <br>(b) H<sub>3</sub>PO<sub>2</sub> + 2CuSO<sub>4</sub> + 2H<sub>2</sub>O &rarr; H<sub>3</sub>PO<sub>4</sub> + 2Cu + 2H<sub>2</sub>SO<sub>4</sub> <br>(c) C<sub>6</sub>H<sub>5</sub>CHO + 2[Ag(NH<sub>3</sub>)<sub>2</sub>]<sup>+</sup> + 3OH<sup>-</sup> &rarr; C<sub>6</sub>H<sub>5</sub>COO<sup>-</sup> + 2Ag + 4NH<sub>3</sub> + 2H<sub>2</sub>O <br>(d) C<sub>6</sub>H<sub>5</sub>CHO + 2Cu<sup>2+</sup> + 5OH<sup>-</sup> &rarr; No change observed. <br>What inference do you draw about the behaviour of Ag<sup>+</sup> and Cu<sup>2+</sup>?"

    * H<sub>3</sub>PO<sub>2</sub> is a strong reductant and reduces both Ag<sup>+</sup> and Cu<sup>2+</sup>.

    * Benzaldehyde is a weaker reductant: it reduces Ag<sup>+</sup> (Tollens' reagent) but not Cu<sup>2+</sup>.

    * Hence, Ag<sup>+</sup> is a stronger oxidising agent than Cu<sup>2+</sup>.

!!! question "Using standard electrode potentials, predict if the reaction between the following is feasible: <br>(a) Fe<sup>3+</sup> and I<sup>-</sup> (b) Ag<sup>+</sup> and Cu (c) Fe<sup>3+</sup> and Cu (d) Ag and Fe<sup>3+</sup> (e) Br<sub>2</sub> and Fe<sup>2+</sup> <br>Given: E<sup>0</sup>(Fe<sup>3+</sup>/Fe<sup>2+</sup>) = 0.77 V, E<sup>0</sup>(I<sub>2</sub>/I<sup>-</sup>) = 0.54 V, E<sup>0</sup>(Ag<sup>+</sup>/Ag) = 0.80 V, E<sup>0</sup>(Cu<sup>2+</sup>/Cu) = 0.34 V, E<sup>0</sup>(Br<sub>2</sub>/Br<sup>-</sup>) = 1.09 V"

    A reaction is feasible if E<sup>0</sup><sub>cell</sub> = E<sup>0</sup>(species reduced) - E<sup>0</sup>(species oxidised) is positive.

    $$(a)\ 2Fe^{3+} + 2I^- &rarr; 2Fe^{2+} + I_2:\ E^0_{cell} = 0.77 - 0.54 = +0.23\ V\ (feasible)$$

    $$(b)\ 2Ag^+ + Cu &rarr; 2Ag + Cu^{2+}:\ E^0_{cell} = 0.80 - 0.34 = +0.46\ V\ (feasible)$$

    $$(c)\ 2Fe^{3+} + Cu &rarr; 2Fe^{2+} + Cu^{2+}:\ E^0_{cell} = 0.77 - 0.34 = +0.43\ V\ (feasible)$$

    $$(d)\ Ag + Fe^{3+} &rarr; Ag^+ + Fe^{2+}:\ E^0_{cell} = 0.77 - 0.80 = -0.03\ V\ (not\ feasible)$$

    $$(e)\ Br_2 + 2Fe^{2+} &rarr; 2Br^- + 2Fe^{3+}:\ E^0_{cell} = 1.09 - 0.77 = +0.32\ V\ (feasible)$$

!!! question "Arrange the following metals in the order in which they displace each other from the solution of their salts: Al, Cu, Fe, Mg and Zn."

    A metal displaces any metal below it in the activity series (more negative E<sup>0</sup> means a stronger reductant):

    $$Mg > Al > Zn > Fe > Cu$$

!!! question "Given the standard electrode potentials: K<sup>+</sup>/K = -2.93 V, Ag<sup>+</sup>/Ag = 0.80 V, Hg<sup>2+</sup>/Hg = 0.79 V, Mg<sup>2+</sup>/Mg = -2.37 V, Cr<sup>3+</sup>/Cr = -0.74 V. Arrange these metals in increasing order of reducing power."

    The lower (more negative) the reduction potential, the greater the reducing power:

    $$Ag < Hg < Cr < Mg < K$$

!!! question "Depict the galvanic cell in which the reaction Zn<sub>(s)</sub> + 2Ag<sup>+</sup><sub>(aq)</sub> &rarr; Zn<sup>2+</sup><sub>(aq)</sub> + 2Ag<sub>(s)</sub> takes place. Show: (i) which electrode is negatively charged (ii) the carriers of current in the cell (iii) the reaction at each electrode."

    $$Zn_{(s)}/Zn^{2+}_{(aq)} || Ag^+_{(aq)}/Ag_{(s)}$$

    * (i) The zinc electrode (anode) is negatively charged, because electrons are released there.

    * (ii) Electrons carry the current in the external wire (from Zn to Ag); ions carry it inside the solutions and through the salt bridge.

    * (iii) Electrode reactions:

    $$Anode:\ Zn_{(s)} &rarr; Zn^{2+}_{(aq)} + 2e^-$$

    $$Cathode:\ 2Ag^+_{(aq)} + 2e^- &rarr; 2Ag_{(s)}$$

## Stoichiometry

!!! question "In Ostwald's process for the manufacture of nitric acid, the first step involves the oxidation of ammonia gas by oxygen gas to give nitric oxide gas and steam. What is the maximum weight of nitric oxide that can be obtained starting only with 10.00 g of ammonia and 20.00 g of oxygen?"

    $$4NH_{3(g)} + 5O_{2(g)} &rarr; 4NO_{(g)} + 6H_2O_{(g)}$$

    $$Moles\ of\ NH_3 = {10.00 \over 17} = 0.588\ mol$$

    $$Moles\ of\ O_2 = {20.00 \over 32} = 0.625\ mol$$

    * O<sub>2</sub> needed for 0.588 mol NH<sub>3</sub>:

    $$0.588 \times {5 \over 4} = 0.735\ mol$$

    * Only 0.625 mol O<sub>2</sub> is available, so **O<sub>2</sub> is the limiting reagent**.

    $$Moles\ of\ NO = 0.625 \times {4 \over 5} = 0.500\ mol$$

    $$Mass\ of\ NO = 0.500 \times 30 = 15.0\ g$$
