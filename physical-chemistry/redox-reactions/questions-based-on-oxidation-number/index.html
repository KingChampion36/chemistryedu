    Redox Reactions | Questions Based on Oxidation Number#

    Questions#

    Assign oxidation number to:
    (a) P in NaH2PO4 (b) S in NaHSO4 (c) P in H4P2O7 (d) Mn in K2MnO4
    (e) O in CaO2 (f) B in NaBH4 (g) S in H2S2O7 (h) S in KAl(SO4)2.12H2O

    Let the oxidation number of the required element be x.

    \[(a)\ NaH_2PO_4:\ +1 + 2(+1) + x + 4(-2) = 0 &rArr; x = +5\]
    \[(b)\ NaHSO_4:\ +1 + 1 + x + 4(-2) = 0 &rArr; x = +6\]
    \[(c)\ H_4P_2O_7:\ 4(+1) + 2x + 7(-2) = 0 &rArr; x = +5\]
    \[(d)\ K_2MnO_4:\ 2(+1) + x + 4(-2) = 0 &rArr; x = +6\]
    • (e) CaO2 is a peroxide:
    \[+2 + 2x = 0 &rArr; x = -1\]
    • (f) NaBH4 is a metal hydride, so H is -1:
    \[+1 + x + 4(-1) = 0 &rArr; x = +3\]
    \[(g)\ H_2S_2O_7:\ 2(+1) + 2x + 7(-2) = 0 &rArr; x = +6\]
    • (h) Water molecules are neutral, so they contribute zero:
    \[+1 + 3 + 2x + 8(-2) = 0 &rArr; x = +6\]

    What are the oxidation numbers of the following and how do you rationalise your results?
    (a) I in KI3 (b) S in H2S4O6 (c) Fe in Fe3O4 (d) C in CH3CH2OH (e) C in CH3COOH

    • (a) By formula, the average oxidation number of I is \(-{1 \over 3}\). But KI3 is K+[I2.I-]: two iodine atoms (the I2 molecule) are 0 and one (the I- ion) is -1.

    • (b) The average oxidation number of S is +2.5. In the structure of S4O62-, the two terminal S atoms are +5 and the two middle S atoms are 0.

    • (c) The average oxidation number of Fe is \(+{8 \over 3}\). Fe3O4 is a mixed oxide, FeO.Fe2O3: one Fe is +2 and two Fe are +3.

    • (d) The average oxidation number of C is -2. Counting each C separately (C-C bond contributes 0, each H contributes -1, each O contributes +1):

    \[\overset{-3}{C}H_3 - \overset{-1}{C}H_2OH\]
    • (e) The average oxidation number of C is 0. Counting separately:
    \[\overset{-3}{C}H_3 - \overset{+3}{C}OOH\]

    Justify that the following reactions are redox reactions:
    (a) CuO(s) + H2(g) → Cu(s) + H2O(g)
    (b) Fe2O3(s) + 3CO(g) → 2Fe(s) + 3CO2(g)
    (c) 2K(s) + F2(g) → 2K+F-(s)
    (d) 4NH3(g) + 5O2(g) → 4NO(g) + 6H2O(g)

    \[(a)\ \overset{+2}{Cu}O + \overset{0}{H_2} &rarr; \overset{0}{Cu} + \overset{+1}{H_2}O\]

    Cu is reduced (+2 to 0) and H is oxidised (0 to +1).

    \[(b)\ \overset{+3}{Fe_2}O_3 + 3\overset{+2}{C}O &rarr; 2\overset{0}{Fe} + 3\overset{+4}{C}O_2\]

    Fe is reduced (+3 to 0) and C is oxidised (+2 to +4).

    \[(c)\ 2\overset{0}{K} + \overset{0}{F_2} &rarr; 2\overset{+1}{K}\overset{-1}{F}\]

    K is oxidised (0 to +1) and F is reduced (0 to -1).

    \[(d)\ 4\overset{-3}{N}H_3 + 5\overset{0}{O_2} &rarr; 4\overset{+2}{N}\overset{-2}{O} + 6H_2\overset{-2}{O}\]

    N is oxidised (-3 to +2) and O is reduced (0 to -2).

    In each reaction, one element is oxidised and another is reduced, so all are redox reactions.

    Fluorine reacts with ice: H2O(s) + F2(g) → HF(g) + HOF(g). Justify that this is a redox reaction.

    In HOF, fluorine is the most electronegative atom (-1) and H is +1, so oxygen is 0.

    \[H_2\overset{-2}{O} + \overset{0}{F_2} &rarr; H\overset{-1}{F} + H\overset{0}{O}\overset{-1}{F}\]

    Oxygen is oxidised from -2 to 0 and fluorine is reduced from 0 to -1. Hence, it is a redox reaction.

    Calculate the oxidation number of sulphur, chromium and nitrogen in H2SO5, Cr2O72- and NO3-. Suggest structures of these compounds. Count for the fallacy.

    • H2SO5: Taking all O as -2:
    \[2(+1) + x + 5(-2) = 0 &rArr; x = +8\]

    This is impossible because sulphur cannot exceed +6 (it has only six valence electrons). The fallacy is that H2SO5 (peroxomonosulphuric acid, HO-SO2-O-O-H) contains one peroxide (O-O) linkage, where each of the two oxygens is -1:

    \[2(+1) + x + 3(-2) + 2(-1) = 0 &rArr; x = +6\]
    • Cr2O72-:
    \[2x + 7(-2) = -2 &rArr; x = +6\]

    The structure has two CrO3 units joined by a bridging oxygen; there is no peroxide linkage, so +6 is correct and there is no fallacy.

    • NO3-:
    \[x + 3(-2) = -1 &rArr; x = +5\]

    In the structure, N forms one N=O double bond, one N-O- single bond and one coordinate bond N→O. N cannot form five covalent bonds (no d-orbitals), but its oxidation number is still +5 since all its five valence electrons are counted towards oxygen.

    While sulphur dioxide and hydrogen peroxide can act as oxidising as well as reducing agents, ozone and nitric acid act only as oxidants. Why?

    • In SO2, S is +4. Sulphur can range from -2 to +6, so its oxidation number can either increase or decrease. Hence SO2 can act as both a reductant and an oxidant.

    • In H2O2, O is -1. It can increase to 0 (in O2) or decrease to -2 (in H2O), so H2O2 can also act both ways.

    • In HNO3, N is +5, its highest oxidation state. It can only decrease, so HNO3 acts only as an oxidant.

    • In O3, O is 0. Oxygen can decrease to -2 but cannot show positive oxidation states (except with fluorine). Ozone readily gives O2 and an oxygen atom, which is a strong oxidant. So ozone acts only as an oxidant.

    The compound AgF2 is unstable. However, if formed, it acts as a very strong oxidising agent. Why?

    In AgF2, silver is in the +2 state, which is unstable. Silver strongly tends to accept an electron and return to its stable +1 state. This makes AgF2 a very strong oxidising agent.

    Identify the substance oxidised, reduced, oxidising agent and reducing agent:
    (a) 2AgBr(s) + C6H6O2(aq) → 2Ag(s) + 2HBr(aq) + C6H4O2(aq)
    (b) HCHO(l) + 2[Ag(NH3)2]+(aq) + 3OH-(aq) → 2Ag(s) + HCOO-(aq) + 4NH3(aq) + 2H2O(l)
    (c) HCHO(l) + 2Cu2+(aq) + 5OH-(aq) → Cu2O(s) + HCOO-(aq) + 3H2O(l)
    (d) N2H4(l) + 2H2O2(l) → N2(g) + 4H2O(l)
    (e) Pb(s) + PbO2(s) + 2H2SO4(aq) → 2PbSO4(s) + 2H2O(l)

    Reaction Oxidised (reducing agent) Reduced (oxidising agent)
    (a) C6H6O2 (hydroquinone) AgBr (Ag: +1 → 0)
    (b) HCHO (C: 0 → +2) [Ag(NH3)2]+ (Ag: +1 → 0)
    (c) HCHO (C: 0 → +2) Cu2+ (Cu: +2 → +1)
    (d) N2H4 (N: -2 → 0) H2O2 (O: -1 → -2)
    (e) Pb (0 → +2) PbO2 (Pb: +4 → +2)

    What information can you draw from the reaction: (CN)2(g) + 2OH-(aq) → CN-(aq) + CNO-(aq) + H2O(l)?

    Taking N as -3, the oxidation number of carbon is:

    \[(\overset{+3}{C}N)_2 + 2OH^- &rarr; \overset{+2}{C}N^- + \overset{+4}{C}NO^- + H_2O\]
    • Carbon in cyanogen (+3) is simultaneously reduced to +2 (cyanide) and oxidised to +4 (cyanate). So this is a disproportionation reaction of cyanogen in alkaline medium.

    Consider the elements Cs, Ne, I and F. Identify the element that exhibits: (a) only negative oxidation state (b) only positive oxidation state (c) both positive and negative oxidation states (d) neither negative nor positive oxidation state.

    • (a) F - being the most electronegative element, it shows only -1.

    • (b) Cs - an alkali metal, it shows only +1.

    • (c) I - shows -1 in iodides and +1, +3, +5, +7 in its oxo compounds.

    • (d) Ne - a noble gas, it shows neither.
