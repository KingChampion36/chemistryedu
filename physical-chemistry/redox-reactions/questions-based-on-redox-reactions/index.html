    Balancing Redox Equations#

    Balance by the ion-electron method: MnO4-(aq) + I-(aq) → MnO2(s) + I2(s) (in basic medium)

    \[Oxidation:\ 2I^- &rarr; I_2 + 2e^-\]
    \[Reduction:\ MnO_4^- + 2H_2O + 3e^- &rarr; MnO_2 + 4OH^-\]
    • Multiply the oxidation half by 3 and the reduction half by 2, then add:
    \[2MnO_4^-{}_{(aq)} + 6I^-_{(aq)} + 4H_2O_{(l)} &rarr; 2MnO_{2(s)} + 3I_{2(s)} + 8OH^-_{(aq)}\]

    Balance by the ion-electron method: MnO4-(aq) + SO2(g) → Mn2+(aq) + HSO4-(aq) (in acidic solution)

    \[Oxidation:\ SO_2 + 2H_2O &rarr; HSO_4^- + 3H^+ + 2e^-\]
    \[Reduction:\ MnO_4^- + 8H^+ + 5e^- &rarr; Mn^{2+} + 4H_2O\]
    • Multiply the oxidation half by 5 and the reduction half by 2:
    \[5SO_2 + 10H_2O &rarr; 5HSO_4^- + 15H^+ + 10e^-\]
    \[2MnO_4^- + 16H^+ + 10e^- &rarr; 2Mn^{2+} + 8H_2O\]
    • Add and cancel the common H+ and H2O:
    \[2MnO_4^-{}_{(aq)} + 5SO_{2(g)} + 2H_2O_{(l)} + H^+_{(aq)} &rarr; 2Mn^{2+}_{(aq)} + 5HSO_4^-{}_{(aq)}\]

    Balance by the ion-electron method: H2O2(aq) + Fe2+(aq) → Fe3+(aq) + H2O(l) (in acidic solution)

    \[Oxidation:\ 2Fe^{2+} &rarr; 2Fe^{3+} + 2e^-\]
    \[Reduction:\ H_2O_2 + 2H^+ + 2e^- &rarr; 2H_2O\]
    \[Overall:\ H_2O_{2(aq)} + 2Fe^{2+}_{(aq)} + 2H^+_{(aq)} &rarr; 2Fe^{3+}_{(aq)} + 2H_2O_{(l)}\]

    Balance by the ion-electron method: Cr2O72- + SO2(g) → Cr3+(aq) + SO42-(aq) (in acidic solution)

    \[Oxidation:\ 3SO_2 + 6H_2O &rarr; 3SO_4^{2-} + 12H^+ + 6e^-\]
    \[Reduction:\ Cr_2O_7^{2-} + 14H^+ + 6e^- &rarr; 2Cr^{3+} + 7H_2O\]
    • Add and cancel 12H+ and 6H2O from both sides:
    \[Cr_2O_7^{2-}{}_{(aq)} + 3SO_{2(g)} + 2H^+_{(aq)} &rarr; 2Cr^{3+}_{(aq)} + 3SO_4^{2-}{}_{(aq)} + H_2O_{(l)}\]

    Balance in basic medium and identify the oxidising and reducing agents: N2H4(l) + ClO3-(aq) → NO(g) + Cl-(aq)

    • Using the oxidation number method:
    \[\overset{-2}{N_2}H_4 + \overset{+5}{Cl}O_3^- &rarr; \overset{+2}{N}O + \overset{-1}{Cl^-}\]
    • Each N increases by 4, so N2H4 increases by 8. Cl decreases by 6. LCM of 8 and 6 is 24, so take 3N2H4 and 4ClO3-:
    \[3N_2H_4 + 4ClO_3^- &rarr; 6NO + 4Cl^-\]
    • Charges are already equal (-4 on each side). Balance H by adding 6H2O on the right:
    \[3N_2H_{4(l)} + 4ClO_3^-{}_{(aq)} &rarr; 6NO_{(g)} + 4Cl^-_{(aq)} + 6H_2O_{(l)}\]
    • Oxidising agent: ClO3-. Reducing agent: N2H4.

    Balance in basic medium and identify the oxidising and reducing agents: Cl2O7(g) + H2O2(aq) → ClO2-(aq) + O2(g)

    \[\overset{+7}{Cl_2}O_7 + H_2\overset{-1}{O_2} &rarr; \overset{+3}{Cl}O_2^- + \overset{0}{O_2}\]
    • Each Cl decreases by 4, so Cl2O7 decreases by 8. Each H2O2 increases by 2. So take 4H2O2:
    \[Cl_2O_7 + 4H_2O_2 &rarr; 2ClO_2^- + 4O_2\]
    • Charge on left = 0, on right = -2. Add 2OH- on the left. Then balance H with 5H2O on the right:
    \[Cl_2O_{7(g)} + 4H_2O_{2(aq)} + 2OH^-_{(aq)} &rarr; 2ClO_2^-{}_{(aq)} + 4O_{2(g)} + 5H_2O_{(l)}\]
    • Oxidising agent: Cl2O7. Reducing agent: H2O2.

    The Mn3+ ion is unstable in solution and undergoes disproportionation to give Mn2+, MnO2 and H+ ion. Write a balanced ionic equation for the reaction.

    \[Oxidation:\ Mn^{3+} + 2H_2O &rarr; MnO_2 + 4H^+ + e^-\]
    \[Reduction:\ Mn^{3+} + e^- &rarr; Mn^{2+}\]
    \[Overall:\ 2Mn^{3+}_{(aq)} + 2H_2O_{(l)} &rarr; Mn^{2+}_{(aq)} + MnO_{2(s)} + 4H^+_{(aq)}\]

    Chlorine is used to purify drinking water. Excess chlorine is removed by treating with sulphur dioxide. Present a balanced equation for this redox change in water.

    \[Reduction:\ Cl_2 + 2e^- &rarr; 2Cl^-\]
    \[Oxidation:\ SO_2 + 2H_2O &rarr; SO_4^{2-} + 4H^+ + 2e^-\]
    \[Overall:\ Cl_{2(aq)} + SO_{2(aq)} + 2H_2O_{(l)} &rarr; 2Cl^-_{(aq)} + SO_4^{2-}{}_{(aq)} + 4H^+_{(aq)}\]

    Oxidants, Reductants and Feasibility#

    Whenever a reaction between an oxidising agent and a reducing agent is carried out, a compound of lower oxidation state is formed if the reducing agent is in excess, and a compound of higher oxidation state is formed if the oxidising agent is in excess. Justify with three illustrations.

    \[(i)\ C + O_2\ (limited) &rarr; CO\ (C:\ +2),\ \ C + O_2\ (excess) &rarr; CO_2\ (C:\ +4)\]
    \[(ii)\ P_4 + 6Cl_2\ (limited) &rarr; 4PCl_3\ (P:\ +3),\ \ P_4 + 10Cl_2\ (excess) &rarr; 4PCl_5\ (P:\ +5)\]
    \[(iii)\ 4Na + O_2\ (limited) &rarr; 2Na_2O\ (O:\ -2),\ \ 2Na + O_2\ (excess) &rarr; Na_2O_2\ (O:\ -1)\]

    In (i) and (ii), the reductant (C, P4) in excess gives the lower oxidation state of the reductant. In (iii), excess oxidant O2 gives Na2O2, where oxygen is in its higher oxidation state (-1 instead of -2).

    When concentrated sulphuric acid is added to an inorganic mixture containing chloride, we get colourless pungent HCl gas, but if the mixture contains bromide, we get red vapour of bromine. Why?

    • With chloride, HCl is formed. HCl is a weak reductant and cannot reduce H2SO4:
    \[NaCl + H_2SO_4 &rarr; NaHSO_4 + HCl\]
    • With bromide, HBr is formed first. HBr is a stronger reductant and reduces H2SO4 to SO2, getting oxidised to red Br2:
    \[NaBr + H_2SO_4 &rarr; NaHSO_4 + HBr\]
    \[2HBr + H_2SO_4 &rarr; Br_2 + SO_2 + 2H_2O\]

    Consider the reactions:
    2S2O32-(aq) + I2(s) → S4O62-(aq) + 2I-(aq)
    S2O32-(aq) + 4Br2(l) + 5H2O(l) → 2SO42-(aq) + 8Br-(aq) + 10H+(aq)
    Why does the same reductant, thiosulphate, react differently with iodine and bromine?

    • In S2O32-, the average oxidation number of S is +2.

    • Iodine is a weaker oxidant, so it oxidises S only to +2.5 (in S4O62-).

    • Bromine is a stronger oxidant, so it oxidises S all the way to +6 (in SO42-).

    Justify giving reactions that among halogens, fluorine is the best oxidant and among hydrohalic compounds, hydroiodic acid is the best reductant.

    • Fluorine has the highest standard reduction potential (2.87 V) and oxidises all other halide ions:
    \[F_2 + 2X^- &rarr; 2F^- + X_2\ \ (X = Cl,\ Br,\ I)\]
    • Among HX, the H-I bond is the weakest and I- is the largest ion, so it loses its electron most easily. HI can even reduce H2SO4, which HCl cannot:
    \[2HI + H_2SO_4 &rarr; I_2 + SO_2 + 2H_2O\]

    Why does the following reaction occur?
    XeO64-(aq) + 2F-(aq) + 6H+(aq) → XeO3(g) + F2(g) + 3H2O(l)
    What conclusion about Na4XeO6 can be drawn from the reaction?

    \[\overset{+8}{Xe}O_6^{4-} + 2\overset{-1}{F^-} + 6H^+ &rarr; \overset{+6}{Xe}O_3 + \overset{0}{F_2} + 3H_2O\]
    • Xe is reduced from +8 to +6 and F- is oxidised to F2. Since F2 is the strongest common oxidant, XeO64- must be an even stronger oxidant. So Na4XeO6 is a stronger oxidising agent than F2.

    Consider the reactions:
    (a) H3PO2 + 4AgNO3 + 2H2O → H3PO4 + 4Ag + 4HNO3
    (b) H3PO2 + 2CuSO4 + 2H2O → H3PO4 + 2Cu + 2H2SO4
    (c) C6H5CHO + 2[Ag(NH3)2]+ + 3OH- → C6H5COO- + 2Ag + 4NH3 + 2H2O
    (d) C6H5CHO + 2Cu2+ + 5OH- → No change observed.
    What inference do you draw about the behaviour of Ag+ and Cu2+?

    • H3PO2 is a strong reductant and reduces both Ag+ and Cu2+.

    • Benzaldehyde is a weaker reductant: it reduces Ag+ (Tollens' reagent) but not Cu2+.

    • Hence, Ag+ is a stronger oxidising agent than Cu2+.

    Using standard electrode potentials, predict if the reaction between the following is feasible:
    (a) Fe3+ and I- (b) Ag+ and Cu (c) Fe3+ and Cu (d) Ag and Fe3+ (e) Br2 and Fe2+
    Given: E0(Fe3+/Fe2+) = 0.77 V, E0(I2/I-) = 0.54 V, E0(Ag+/Ag) = 0.80 V, E0(Cu2+/Cu) = 0.34 V, E0(Br2/Br-) = 1.09 V

    A reaction is feasible if E0cell = E0(species reduced) - E0(species oxidised) is positive.

    \[(a)\ 2Fe^{3+} + 2I^- &rarr; 2Fe^{2+} + I_2:\ E^0_{cell} = 0.77 - 0.54 = +0.23\ V\ (feasible)\]
    \[(b)\ 2Ag^+ + Cu &rarr; 2Ag + Cu^{2+}:\ E^0_{cell} = 0.80 - 0.34 = +0.46\ V\ (feasible)\]
    \[(c)\ 2Fe^{3+} + Cu &rarr; 2Fe^{2+} + Cu^{2+}:\ E^0_{cell} = 0.77 - 0.34 = +0.43\ V\ (feasible)\]
    \[(d)\ Ag + Fe^{3+} &rarr; Ag^+ + Fe^{2+}:\ E^0_{cell} = 0.77 - 0.80 = -0.03\ V\ (not\ feasible)\]
    \[(e)\ Br_2 + 2Fe^{2+} &rarr; 2Br^- + 2Fe^{3+}:\ E^0_{cell} = 1.09 - 0.77 = +0.32\ V\ (feasible)\]

    Arrange the following metals in the order in which they displace each other from the solution of their salts: Al, Cu, Fe, Mg and Zn.

    A metal displaces any metal below it in the activity series (more negative E0 means a stronger reductant):

    \[Mg > Al > Zn > Fe > Cu\]

    Given the standard electrode potentials: K+/K = -2.93 V, Ag+/Ag = 0.80 V, Hg2+/Hg = 0.79 V, Mg2+/Mg = -2.37 V, Cr3+/Cr = -0.74 V. Arrange these metals in increasing order of reducing power.

    The lower (more negative) the reduction potential, the greater the reducing power:

    \[Ag < Hg < Cr < Mg < K\]

    Depict the galvanic cell in which the reaction Zn(s) + 2Ag+(aq) → Zn2+(aq) + 2Ag(s) takes place. Show: (i) which electrode is negatively charged (ii) the carriers of current in the cell (iii) the reaction at each electrode.

    \[Zn_{(s)}/Zn^{2+}_{(aq)} || Ag^+_{(aq)}/Ag_{(s)}\]

    • (i) The zinc electrode (anode) is negatively charged, because electrons are released there.

    • (ii) Electrons carry the current in the external wire (from Zn to Ag); ions carry it inside the solutions and through the salt bridge.

    • (iii) Electrode reactions:

    \[Anode:\ Zn_{(s)} &rarr; Zn^{2+}_{(aq)} + 2e^-\]
    \[Cathode:\ 2Ag^+_{(aq)} + 2e^- &rarr; 2Ag_{(s)}\]

    Stoichiometry#

    In Ostwald's process for the manufacture of nitric acid, the first step involves the oxidation of ammonia gas by oxygen gas to give nitric oxide gas and steam. What is the maximum weight of nitric oxide that can be obtained starting only with 10.00 g of ammonia and 20.00 g of oxygen?

    \[4NH_{3(g)} + 5O_{2(g)} &rarr; 4NO_{(g)} + 6H_2O_{(g)}\]
    \[Moles\ of\ NH_3 = {10.00 \over 17} = 0.588\ mol\]
    \[Moles\ of\ O_2 = {20.00 \over 32} = 0.625\ mol\]
    • O2 needed for 0.588 mol NH3:
    \[0.588 \times {5 \over 4} = 0.735\ mol\]
    • Only 0.625 mol O2 is available, so O2 is the limiting reagent.
    \[Moles\ of\ NO = 0.625 \times {4 \over 5} = 0.500\ mol\]
    \[Mass\ of\ NO = 0.500 \times 30 = 15.0\ g\]
