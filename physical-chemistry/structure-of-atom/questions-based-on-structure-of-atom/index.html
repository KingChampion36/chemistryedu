    Questions on Photons and Photoelectric Effect#

    Yellow light emitted from a sodium lamp has a wavelength (λ) of 580 nm. Calculate the frequency (ν) and wavenumber of the yellow light.

    \[&nu; = {c \over &lambda;} = {3 \times 10^8 \over 580 \times 10^{-9}} = 5.17 \times 10^{14}\ s^{-1}\]
    \[\bar{\nu} = {1 \over &lambda;} = {1 \over 580 \times 10^{-9}} = 1.72 \times 10^6\ m^{-1}\]

    Find energy of each of the photons which
    (i) correspond to light of frequency 3 × 1015 Hz
    (ii) have wavelength of 0.50 Å.

    \[(i)\ E = h&nu; = 6.626 \times 10^{-34} \times 3 \times 10^{15} = 1.988 \times 10^{-18}\ J\]
    \[(ii)\ E = {hc \over &lambda;} = {6.626 \times 10^{-34} \times 3 \times 10^8 \over 0.50 \times 10^{-10}} = 3.98 \times 10^{-15}\ J\]

    What is the number of photons of light with a wavelength of 4000 pm that provide 1 J of energy?

    \[E = {hc \over &lambda;} = {6.626 \times 10^{-34} \times 3 \times 10^8 \over 4000 \times 10^{-12}} = 4.97 \times 10^{-17}\ J\]
    \[Number\ of\ photons = {1 \over 4.97 \times 10^{-17}} = 2.01 \times 10^{16}\]

    Electromagnetic radiation of wavelength 242 nm is just sufficient to ionise the sodium atom. Calculate the ionisation energy of sodium in kJ mol-1.

    \[E = {hc \over &lambda;} = {6.626 \times 10^{-34} \times 3 \times 10^8 \over 242 \times 10^{-9}} = 8.21 \times 10^{-19}\ J\]
    \[Ionisation\ energy = 8.21 \times 10^{-19} \times 6.022 \times 10^{23} = 4.94 \times 10^5\ J\ mol^{-1}\]
    \[Ionisation\ energy = 494\ kJ\ mol^{-1}\]

    Electrons are emitted with zero velocity from a metal surface when it is exposed to radiation of wavelength 6800 Å. Calculate threshold frequency (ν0) and work function (W0) of the metal.

    • Since electrons are emitted with zero velocity, the photon energy just equals the work function.
    \[&nu;_0 = {c \over &lambda;_0} = {3 \times 10^8 \over 6800 \times 10^{-10}} = 4.41 \times 10^{14}\ s^{-1}\]
    \[W_0 = h&nu;_0 = 6.626 \times 10^{-34} \times 4.41 \times 10^{14} = 2.92 \times 10^{-19}\ J\]

    Questions on Bohr's Model and Hydrogen Spectrum#

    What is the wavelength of light emitted when the electron in a hydrogen atom undergoes transition from an energy level with n = 4 to an energy level with n = 2?

    \[&Delta;E = 2.18 \times 10^{-18}\left({1 \over 2^2} - {1 \over 4^2}\right) = 2.18 \times 10^{-18} \times {3 \over 16}\]
    \[&Delta;E = 4.09 \times 10^{-19}\ J\]
    \[&lambda; = {hc \over &Delta;E} = {6.626 \times 10^{-34} \times 3 \times 10^8 \over 4.09 \times 10^{-19}} = 4.86 \times 10^{-7}\ m = 486\ nm\]

    How much energy is required to ionise a H atom if the electron occupies n = 5 orbit? Compare your answer with the ionization enthalpy of H atom (energy required to remove the electron from n = 1 orbit).

    \[E_5 = -{2.18 \times 10^{-18} \over 5^2} = -8.72 \times 10^{-20}\ J\]
    \[Energy\ required\ (n = 5 &rarr; &infin;) = 0 - (-8.72 \times 10^{-20}) = 8.72 \times 10^{-20}\ J\]
    \[Energy\ required\ (n = 1 &rarr; &infin;) = 2.18 \times 10^{-18}\ J\]
    \[{2.18 \times 10^{-18} \over 8.72 \times 10^{-20}} = 25\]

    So, 25 times more energy is needed to remove the electron from n = 1 than from n = 5.

    What is the maximum number of emission lines when the excited electron of a H atom in n = 6 drops to the ground state?

    \[Number\ of\ lines = {n(n-1) \over 2} = {6 \times 5 \over 2} = 15\]

    (i) The energy associated with the first orbit in the hydrogen atom is –2.18 × 10-18 J atom-1. What is the energy associated with the fifth orbit?
    (ii) Calculate the radius of Bohr's fifth orbit for hydrogen atom.

    \[(i)\ E_5 = -{2.18 \times 10^{-18} \over 5^2} = -8.72 \times 10^{-20}\ J\]
    \[(ii)\ r_5 = n^2 a_0 = 25 \times 52.9\ pm = 1322.5\ pm = 1.3225\ nm\]

    Calculate the wavenumber for the longest wavelength transition in the Balmer series of atomic hydrogen.

    • Longest wavelength means smallest energy gap. In the Balmer series, this is n = 3 to n = 2.
    \[\bar{\nu} = 109677\left({1 \over 2^2} - {1 \over 3^2}\right) = 109677 \times {5 \over 36}\]
    \[\bar{\nu} = 15233\ cm^{-1} = 1.523 \times 10^6\ m^{-1}\]

    The electron energy in hydrogen atom is given by En = (–2.18 × 10-18)/n2 J. Calculate the energy required to remove an electron completely from the n = 2 orbit. What is the longest wavelength of light in cm that can be used to cause this transition?

    \[&Delta;E = E_&infin; - E_2 = 0 - \left(-{2.18 \times 10^{-18} \over 4}\right) = 5.45 \times 10^{-19}\ J\]
    \[&lambda; = {hc \over &Delta;E} = {6.626 \times 10^{-34} \times 3 \times 10^8 \over 5.45 \times 10^{-19}} = 3.65 \times 10^{-7}\ m\]
    \[&lambda; = 3.65 \times 10^{-5}\ cm\]

    What transition in the hydrogen spectrum would have the same wavelength as the Balmer transition n = 4 to n = 2 of He+ spectrum?

    \[For\ He^+:\ \bar{\nu} = R Z^2\left({1 \over 2^2} - {1 \over 4^2}\right) = R \times 4 \times {3 \over 16} = {3R \over 4}\]
    \[For\ H:\ R\left({1 \over n_1^2} - {1 \over n_2^2}\right) = {3R \over 4}\]
    \[\left({1 \over n_1^2} - {1 \over n_2^2}\right) = {3 \over 4} = {1 \over 1^2} - {1 \over 2^2}\]

    So the transition is n = 2 to n = 1 (first line of Lyman series).

    Calculate the energy required for the process: He+(g) → He2+(g) + e–.
    The ionization energy for the H atom in the ground state is 2.18 × 10-18 J atom-1.

    \[E_n = -2.18 \times 10^{-18} \times {Z^2 \over n^2}\]
    \[For\ He^+,\ Z = 2,\ n = 1:\ E_1 = -2.18 \times 10^{-18} \times 4 = -8.72 \times 10^{-18}\ J\]
    \[Energy\ required = 8.72 \times 10^{-18}\ J\]

    Emission transitions in the Paschen series end at orbit n = 3 and start from orbit n, and can be represented as ν = 3.29 × 1015 (Hz) [1/32 – 1/n2]. Calculate the value of n if the transition is observed at 1285 nm. Find the region of the spectrum.

    \[&nu; = {c \over &lambda;} = {3 \times 10^8 \over 1285 \times 10^{-9}} = 2.335 \times 10^{14}\ Hz\]
    \[{1 \over 9} - {1 \over n^2} = {2.335 \times 10^{14} \over 3.29 \times 10^{15}} = 0.0710\]
    \[{1 \over n^2} = 0.1111 - 0.0710 = 0.0401\]
    \[n^2 = 24.9 &asymp; 25,\ so\ n = 5\]

    The radiation of 1285 nm lies in the infrared region.

    Questions on Quantum Numbers#

    What is the lowest value of n that allows g orbitals to exist?

    • For g orbitals, l = 4. Since l can be at most (n – 1), n – 1 = 4, so n = 5.

    An electron is in one of the 3d orbitals. Give the possible values of n, l and ml for this electron.

    \[n = 3,\ l = 2,\ m_l = -2, -1, 0, +1, +2\]

    Explain, giving reasons, which of the following sets of quantum numbers are not possible.
    (a) n = 0, l = 0, ml = 0, ms = +½
    (b) n = 1, l = 0, ml = 0, ms = –½
    (c) n = 1, l = 1, ml = 0, ms = +½
    (d) n = 2, l = 1, ml = 0, ms = –½
    (e) n = 3, l = 3, ml = –3, ms = +½
    (f) n = 3, l = 1, ml = 0, ms = +½

    • (a) Not possible, because n cannot be zero.

    • (b) Possible (1s orbital).

    • (c) Not possible, because for n = 1, l can only be 0.

    • (d) Possible (2p orbital).

    • (e) Not possible, because for n = 3, l can be 0, 1 or 2 only.

    • (f) Possible (3p orbital).

    How many electrons in an atom may have the following quantum numbers?
    (a) n = 4, ms = –½ (b) n = 3, l = 0

    • (a) For n = 4, total electrons = 2n2 = 32. Half of them have ms = –½. So, 16 electrons.

    • (b) n = 3, l = 0 is the 3s orbital, which can hold 2 electrons.

    (a) How many sub-shells are associated with n = 4? (b) How many electrons will be present in the sub-shells having ms value of –½ for n = 4?

    • (a) For n = 4, l = 0, 1, 2, 3. So there are 4 sub-shells: 4s, 4p, 4d and 4f.

    • (b) Number of orbitals = n2 = 16. Each orbital has one electron with ms = –½. So, 16 electrons.

    Which of the following are isoelectronic species, i.e. those having the same number of electrons?
    Na+, K+, Mg2+, Ca2+, S2–, Ar

    Species Na+ K+ Mg2+ Ca2+ S2– Ar
    Electrons 10 18 10 18 18 18

    • Na+ and Mg2+ are isoelectronic (10 electrons).

    • K+, Ca2+, S2– and Ar are isoelectronic (18 electrons).
